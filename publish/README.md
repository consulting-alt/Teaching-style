# 智蛙报告风格导入目录

本目录**仅交付供** 智蛙 Skill **智蛙接入中心导入的报告风格文件**，不再混放通用 Agent 解题 Skill。

更新日期：2026-09-14。当前共 **10 位老师、11 份风格文件**：**申论 7 份、面试 4 份**，其中张小龙同时提供申论与面试风格。

## 目录与展示规则

- `style.essay.md`：申论报告风格，`subject: essay`。
- `style.interview.md`：面试报告风格，`subject: interview`。
- 仅保留至少有一份上述风格文件的老师目录；没有风格文件的老师不在本目录展示，也不列为智蛙可导入风格。
- 本 README 是说明文档，**不要作为风格导入**。
- 以下“支持”仅指当前已提供对应科目的协议风格文件，不代表老师只教授该科目，也不代表文件已经导入某个账号或已在生产环境启用。

## 如何导入智蛙

1. 从上方选择老师与科目，打开对应的 `style.essay.md` 或 `style.interview.md`。
2. 将文件全文（包括开头 `---` 包围的元信息）粘贴到智蛙接入中心的报告风格导入入口，或通过 MCP `save_style` 保存。
3. 按对应科目启用风格；使用 MCP 时，通过 `select_style` 指定 `subject` 和风格文件头部的 `id`，不要用老师目录名代替 `id`。
4. 启用后，新提交的对应科目任务使用当前风格快照；不会自动重写旧报告。

导入协议固定为 `washine-report-style/v1`，头部必需字段为 `id`、`name`、`version`、`subject`、`protocol`。当前 `washine-mcp` 代码支持 `essay` 与 `interview` 两类；实际保存与启用以目标环境返回结果为准，本清单不代表已完成线上导入验证。

## 使用边界

- 风格用于报告的分析方法、点评、答案改写与训练建议，不替换既有评分分数结构。
- 内容基于已收集材料蒸馏，不是老师本人发言、人格模仿或官方授权声明。
- 不承诺固定分数、押题命中或完整还原课程；没有材料支持的方法、事实与教师原话不得补造。
- 本目录以实际存在的风格文件为准；旧的项目总览或 `_meta` 解题 Skill 目录不作为智蛙导入清单。
