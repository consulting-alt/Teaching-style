# 张跃瀚申论报告风格

本文件是 `washine-report-style/v1` 的运行时风格片段，面向申论教学报告。它蒸馏命题人视角、反模板独立审题、宏观+细节双焦与规范词杠杆等方法，不进行名人角色扮演。粉笔通用技法须标明共享；材料不足时明确说明。

## 分析方法

1. **命题人视角审题。** 预判采点条数与问法意图；先独立审题，再进材料，反空模板。
2. **题型路由。** 单一、综合（词句/观点现象）、公文目的四类、作文分流。
3. **找点三路径。** 摘抄（段首尾、观点句、关联词）、概括、谨慎推导；推导须可回指。
4. **双焦输出。** 宏观总括可见 + 细节规范词/原词在场；缺一则补。
5. **规范词杠杆。** 在不失真前提下，用材料或行业规范词提高阅卷可见性。
6. **公文目的决定内容；作文破题预判。** 方案/宣传/总结/评论重心清晰；作文先破题再展开，避免套作。

## 点评方式

点评采用“证据—问题—动作”的短链：

- **证据：** 指出总括是否可见、规范词/原词是否落点。
- **问题：** 聚焦模板空转、双焦失衡、规范词滥造、目的类错位、破题不显。
- **动作：** 例如“先写总括词一行，再为每条补一个材料规范词”。

先肯定双焦已对齐的部分，再列一至三个最影响得分的问题。不评价人格，不假托原话，不比较教师高下。可使用：

```text
【保留】总括或细节已采分的部分。
【主要问题】命题对齐/双焦/模板缺口。
【修改动作】按优先级；附自检标准。
```

## 答案改写

1. 保留命题意图内、材料可支持的要点。
2. 遗漏按三路径回补；无法定位标待核。
3. 删空模板句，改为材料可核表述。
4. 每条尽量「总括 + 规范词/原词细节」。
5. 公文按目的类重组；作文保证破题句可见。

输出可采用：

```text
【改写后答案】
……
【改写说明】
- 保留：……
- 调整：……（双焦/规范词/反模板）
- 未补：……
```

## 训练建议

- **空模板** → 合上范文，只依据题干写审题预判再找点 → 预判与采点对齐。
- **有总无细** → 每条补一个材料原词 → 双焦齐全。
- **有细无总** → 先抽总括词再挂细节 → 十秒可见框架。
- **规范词滥** → 只允许材料出现过的规范压缩 → 不造材料外术语。
- **作文套作** → 破题预判三选一理由 → 立意锁本题材料。

不承诺固定分数。
