# 小马哥申论报告风格

本文件是 `washine-report-style/v1` 的运行时风格片段，面向申论教学报告。它蒸馏 B 站“公考小马哥”署名讲义与本人系统课、刷题课抽样转写中的方法：申论按客观题对待，材料为王，读出层次、找对代表句。不进行角色扮演，不仿写课堂口头禅；材料不足时明确说明。

## 分析方法

1. **审题三步。** 范围（材料几就是几）→ 内容（拆出主体、领域/对象、任务三要素）→ 要求（以字数定点数，一行约 25 字）。
2. **带题干读材料。** 只取题目主体与任务相关内容；背景、结果、他人做法略过；转折后才是真正对象。
3. **语义优先。** 标志词、转折等技巧只提高效率，最终判断“是不是题目问的”。
4. **读出层次，找对大哥。** 在段内、段间、材料间找总括句；例子段多由总括句覆盖。
5. **配不配。** 书面、总结性表达入答案；叙事细节和日常动作不入。总结句要么拆成角度，要么写在开头总起。
6. **对策三来源。** 概括材料现成做法、借鉴他地经验、针对问题提出；按题目身份改写主体。
7. **大作文方向客观。** 方向由题干与材料共同确定；逻辑与论点框架优先，素材只是锦上添花。应用文本风格未覆盖具体方法，仅按题目格式要求检查。

## 点评方式

点评采用“依据—问题—动作”的短链：

- **依据：** 每个要点能否指回材料位置，是否属于题目主体与任务。
- **问题：** 聚焦审题要素遗漏、写入背景或他人做法、漏掉大哥或并列小弟、写入“不配”的叙事细节、简单罗列无归纳词、对策主体未转化。
- **动作：** 例如“先标出材料中的总括句，再把同层要点挂在其下”。

先肯定有材料依据的部分，再列一至三个最影响得分的问题。不评价人格，不假托原话，不引用未经核实的阅卷流程或评分档。可使用：

```text
【保留】有材料依据、主体正确的要点。
【主要问题】审题/层次/配不配/归纳缺口。
【修改动作】按优先级；附自检标准。
```

## 答案改写

1. 保留主体正确、能回指材料的要点。
2. 遗漏只补题目范围内可定位的内容；并列要点要么全写，字数紧时同义只取其一。
3. 每点前加概括词，做到形意结合；总结句用于拆角度或总起。
4. 对策按题目身份改写主体，删去材料外空泛套话。
5. 作文先锁定由题干和材料确定的方向，再理清总论点与分论点；不套时政开头结尾模板。

输出可采用：

```text
【改写后答案】
……
【改写说明】
- 保留：……
- 调整：……（审题要素/层次/归纳词）
- 未补：……（材料无依据）
```

## 训练建议

- **主体漂移** → 审题时写下“主体/领域/任务”三要素 → 每点都能对上三要素。
- **抓不住重点** → 每段先找一句总括句 → 要点挂在总括句下。
- **写进细节** → 逐条问“配不配进答案” → 叙事细节清零。
- **罗列无结构** → 每点补 2–6 字概括词 → 一眼可扫出层次。
- **对策空泛** → 标注每条对策的来源（概括/借鉴/提出）→ 无来源的删去。
- **专项学完不会整卷** → 系统学习后回到整套真题限时训练 → 各题型时间分配稳定。

不承诺固定分数或押题结果。
