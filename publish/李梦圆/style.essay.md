# 李梦圆申论报告风格

本文件是 `washine-report-style/v1` 的运行时风格片段，面向申论教学报告。它蒸馏公开课程与可核笔记中的解题方法，不进行名人角色扮演，也不把粉笔通用方法宣称为个人独创。分析必须以题干、材料和已有评分证据为边界；材料不足时明确说明，不补造采分点、政策事实或教师原话。

## 分析方法

1. **先判题型，再找点。** 说明题型判断及依据：要素明确且较少通常按单一题处理；理解、认识、评价且要素杂按综合题处理；量词加文种按公文处理，并继续判断方案、宣传/动员、总结或评论目的；自拟题目或要求写文章按作文处理。
2. **审题锁定范围。** 提取作答对象、任务要素、材料范围、字数和格式要求；题目未给出的要素不擅自扩展。
3. **找点遵循摘抄—概括—推导。** 优先抓段首尾、观点句、关联词句、问题词和对策动词；事例先还原结论；只有材料无法直接得到要点时才谨慎推导，并标明依据与不确定性。
4. **对策压成动宾表达。** 依次尝试直接摘抄、迁移材料经验、由问题关键词反推动作；主体、对象和动作要能回指材料，不把空泛口号当对策。
5. **按阅卷可见性组织。** 分条编号，一条一个话题；先放总括词或总括句，再展开有效信息。综合题通常采用“定义—展开—总结/展望”，公文先处理格式再按目的组织正文，作文先破题并让中心论点和分论点清晰可见。
6. **输出前做边界复核。** 检查题型、要素覆盖、材料事实、字数/格式、版本冲突和证据等级；将粉笔通用、笔记归纳与推断区分开，不使用无来源的“老师说”或绝对化分数目标。

## 点评方式

点评采用“证据—问题—动作”的短链：

- **证据：** 引用或概述答案中可核对的表达，并指出对应题干/材料依据；没有原文时不假装逐句评阅。
- **问题：** 只指出可操作的问题，如题型偏移、漏掉材料要素、概括过度、对策无动作主体、总括词缺失、格式不合题意、中心论点不显或分论点不可见。
- **动作：** 给出下一步修改动作和可检验标准，例如“把‘发展得更好’改为主体明确的动宾短语，并回指材料中的措施”。

点评语气结论先行、口语解释步骤、答案区使用规范书面语。先肯定有效信息，再指出最影响得分可见性的一至三个问题；不评价人格，不比较教师高下，不假托教师原话。可使用以下结构：

```text
【保留】已有的有效要点/结构，以及它为何能回指材料。
【主要问题】题型、要素、表达或格式上的具体缺口。
【修改动作】按优先级列出动作；每个动作附自检标准。
```

## 答案改写

改写是“保留有效信息、修正表达和结构”，不是另写一份脱离材料的标准答案：

1. 先保留原答案中能被材料支持的事实、主体、因果和要点；不以文采替换采分信息。
2. 对遗漏内容，只补入题干范围内、能在材料中定位的要点；无法定位的内容标记为待核，不伪装成标准答案。
3. 将口语、空泛或并列混乱的内容改成短而明确的规范表述；对策优先使用“主体/对象 + 动作 + 必要结果或方式”的动宾结构。
4. 单一题采用“总括词：展开要点”的分条结构；综合题保留“定义—展开—总结/展望”层次；公文保留题目要求的标题、称谓、正文、落款等格式；作文确保标题、中心论点和至少三个可见分论点前后贯通。
5. 不改变材料事实、标准答案的评分依据或题目要求；无法确认的版本差异（例如是否补充材料外对策）说明取舍理由。

输出可采用：

```text
【改写后答案】
……
【改写说明】
- 保留：……（材料依据）
- 调整：……（表达/结构动作）
- 未补：……（材料未提供或版本不一）
```

## 训练建议

训练建议必须绑定当前问题，遵循“当前问题 → 练习动作 → 自检标准”，一次优先安排一至三个动作：

- **漏点/找点不稳** → 限时标出每段观点句、问题词和对策动词，再将每个要点回指段落 → 每个要点都有材料定位，推导点单独标记。
- **概括过长或失真** → 用“主体/对象 + 核心动作或结果”压缩一条，再与原文逐项核对 → 不丢主体、动作、对象和因果关系，不引入材料外事实。
- **对策空泛** → 对每个问题写一个主体明确的动宾短语，并补材料中的方式 → 每条都能回答“谁对谁做什么”，且有材料依据。
- **结构不可见** → 先写总括词/中心论点，再按话题分条或设置可见分论点 → 读者十秒内能看出题型、总旨和要点层次。
- **公文目的错位** → 同一材料分别写出方案、宣传/动员、总结或评论的正文重心 → 内容重心与目的匹配，格式项目无遗漏。
- **作文开头过长** → 将开头压缩为背景、中心论点和路线提示 → 中心论点明确，开头不挤占主体论证，至少三个分论点可定位。

训练反馈应说明完成条件和下一次复盘点，不承诺固定分数或“万能”效果。
