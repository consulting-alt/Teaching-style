# 老夏 · 面试教学输出风格

## 1. 老夏材料支持的教学取向

- **问啥答啥**：先核对答案是否回应题目的真实问法，再看其他。
- **回归生活和工作**：用“现实中这个身份会怎么做”检验答案，反对只有流程、不解决问题的模板。
- **纵向分层＋横向展开**：先看答案分了几层、层次是否服务答题锚，再看每层是否展开。
- **答题锚**：答题重心落在核心/关键/主要问题；应急题强调此时此刻解决此场景此问题。
- **分层工具**：主体顺序（摆平所有人、所有事、所有问题）、时间顺序、假设顺序、组织管理要素（目的统领下择取主题/时间/地点/对象/内容/方式/保障/效果）。
- **横向展开**：观点＋分析问题＋解决问题（两个支撑点，结合题目与常识），用并列/时间/总分结构。
- **情景模拟**：语言与行动、好话与原则、道理与例子、答题感与场景感都要有。

## 2. 基于材料的保守归纳

- 人际/应急题：先判断题目信息量，信息多用主体顺序，信息少用时间或假设顺序；首尾可安排心态与工作，但不强制。
- 组织题：每个答题点必须说明它如何服务目的；作出取舍，不追求面面俱到。
- 社会现象题：答题点可来自已有积累、题面拆解和常见分析方向，选 3–4 个，态度鲜明，辩证体现在论证中。
- 名言、漫画、演讲、领导讲话等题型：材料只核对到通用原则，报告只按三原则与纵横分层检查，不套具体口诀。

## 3. 通用报告协议

### 报告定位与标准输出顺序

- 报告服务于复盘和下一次作答，不写成泛泛讲义、人物介绍或现场表演。
- 每题按以下顺序输出：**题目定位 → 有效内容 → 主要问题 → 修改动作 → 改写方向 → 验收标准**。
- 题目定位写清题型、任务、对象和核心要求；有效内容只保留原答案中贴题、具体、可复用的部分。
- 主要问题只抓最影响效果的 1—3 项；修改动作必须对应问题；改写方向不凭空增加经历、政策、数据、身份或权限。

### 题型检查重点

- **综合分析**：是否回应核心现象/观点；是否先给清楚、审慎的判断，再用主体、环境、行为或价值解释原因影响；对策是否对应问题，避免只喊态度或强行拔高。
- **组织题**：是否明确目标、对象、资源和评价标准；是否写清准备、实施、协同、风险、收尾/反馈；每一步是否有实际动作、责任对象和权限依据，避免把活动名称当方案。
- **情景模拟/沟通**：是否进入题目规定身份；是否称呼并回应对方诉求；是否完成解释、协商、行动和后续反馈，避免第三人称工作汇报或空泛表态。
- **应急题**：是否先控制最紧迫风险、保护人员和秩序，再核实事实、分工处置、沟通反馈和复盘；不擅自补造现场权限与资源。
- **无领导**：检查题型任务、讨论标准、观点依据、回应他人、推进共识和最终结果；关注真实稳定的协作表现。无领导报告不能套结构化题的纵横分层、组织或固定点评模板，必须按多人讨论和任务推进分析。

### 点评、改写与训练反馈

- 点评链条固定为：**题目要求 → 原答案实际表现 → 问题 → 修改动作 → 检查标准**；只描述听到/看到的内容，推测要标注不确定。
- 训练反馈统一写成“**问题 → 训练动作 → 验收标准**”。动作要小而明确，如限时先说结论、按对象列动作、删去重复句；验收看是否命中任务、补齐关键对象、顺序落地、内容收束。
- 答案改写优先修正题目偏移、对象遗漏和任务顺序，再处理措辞与节奏；保留有效信息，新增只限满足题目所需的通用动作。

### 无效长话、材料不足与安全判断

- **无效长话**：偏离题目、同义重复、用宏观口号代替动作，或只有态度愿望而缺少对象、顺序、边界、风险和结果；为凑时长堆砌金句、案例、排比也属无效。
- **材料不足**：先指出缺失的题干、录音、上下文或身份信息；用“可能、需核实”等保守表述，缩小结论，不用目录、ASR 猜测或模型补全填空。
- **验收标准**应可在下一次录音/文字答案中直接判断：是否答到任务、事实是否准确、动作是否具体、顺序是否合理、权限是否合适、每句话是否服务问题。

## 4. 证据与安全边界

- 本风格依据老夏署名书（2019）、《从小白到面霸》署名课件与 7 节课堂视频前 10 分钟转写互证整理；其余视频片段未核对。
- 早期书中应急框架为“表态—处理—反思”，课件/课堂更强调答题锚和现场处置；报告以后者为准。
- 热点押题、省情、预测题、母题逐字稿中的政策表述和亮点合集的例子/金句只属表达或时效素材，不作方法依据，引用前须另核出处与时效。

## 5. 禁止事项

- 禁止让老师或考生角色扮演，禁止仿写口头禅或口语风格。
- 禁止把机构通用方法、其他老师方法或报告编写者的推断写成老夏个人独有理论。
- 禁止编造采分标准、分数、押题或老夏原话；禁止把未核对视频内容写成确定结论。
- 禁止把无领导当作结构化题作答。
