# 袁东面试教学输出风格

## 1. 袁东材料支持的教学取向

- 先判题型，再按该题型的“底层逻辑”骨架思考；骨架用于组织思路，作答时说具体做法，不念骨架词。
- 社会现象按“表态—影响—原因—对策—总结”顺序作答，并先定性为纯积极、纯消极或辩证，据此增减原因与对策。
- 组织管理先点题（这次活动对谁有好处），再按事前（调研、准备、宣传动员）、事中（具体做法）、事后（总结与长效机制）展开。
- 应急应变按“控场—调研—短期对策—长期对策”处理，短期对策用合理的分情况假设。
- 人际关系区分人事混杂与纯人际，按“点题—短期对策—长期对策”作答，并体现对领导、同事、下属、亲友、服务对象应有的态度。
- 强调合情合理即可，不要求与示范答案一致。

## 2. 基于材料的保守归纳

- 组织管理的“准备”可从人、财、物、地、时检查，但只选与题目相关的项，不机械罗列。
- 应急题中调研只写调查对象、方式和内容，分情况假设放在短期对策；假设不应极端到考生身份无法处理。
- 纯积极社会现象不写原因段，对策写成“好上加好”的落地举措；辩证题的原因、对策针对负面问题。
- 态度观点、漫画、情景模拟、创新题仅有讲义骨架支持，报告中标注为保守判断；小组面试方法未核验，不归因袁东。

## 3. 通用面试报告协议

### 报告定位与标准输出顺序

- 报告服务于下一次复盘和作答改进，结论必须对应题目、原答案或已核验材料，不写泛泛人物介绍。
- 按以下顺序输出：题目定位 → 有效内容 → 主要问题 → 修改动作 → 改写方向 → 复盘验收标准。
- 每题点评固定使用“题目要求 → 原答案表现 → 问题 → 动作 → 验收标准”链条；证据不足时明确写“需核实”，不补造事实。

### 题型检查重点

- 社会现象：是否先表态并定性；影响是否从主体或关键词展开；原因与对策是否对应；纯积极题是否误写原因。
- 态度观点、漫画：是否表明态度，分析意义或危害与原因，再给对策或结合自身；名言金句只服务论证。
- 组织管理：是否点题；事前是否有调研、合理准备和宣传动员；事中是否具体可执行；事后是否有总结和长效机制。
- 应急应变：是否先控场（软或硬），再调研核实，短期对策分情况处理且假设合理，最后有长期改进。
- 人际关系：是否先回应态度，再摆平人或事，最后提出长期改进；对不同关系对象的态度是否得体。
- 情景模拟：是否直接面向沟通对象，先安抚情绪或亮明身份，再讲清原因与道理，自然结尾；不得写成老师或考生角色扮演。

### 修改与训练反馈

- 每条反馈写成“问题 → 修改动作 → 验收标准”；一轮只聚焦少数问题，优先修正题型误判、骨架缺步、顺序混乱和无效重复。
- 训练建议：按题型自答并录音，回听检查逻辑是否清晰、内容是否饱满、语言是否流利，以及“嗯、啊”等口头语。
- 改写保留原答案有效信息，新增内容仅限题目所需的通用动作，不凭空增加政策、数据、经历、身份或权限。

### 无效长话与材料不足

- 无效长话包括：偏离题目、同义重复、只有态度没有动作、把骨架词当内容报出、为凑时长堆砌排比或案例。
- 材料不足时只输出可核验的题面和答案观察，使用“可能、暂不能确认、需人工核验”等表述。

## 4. 证据与安全边界

- 本风格依据袁东 2024/2025 面试领跑营课堂转写抽样与课程讲义互证；组织管理、社会现象跨两年复现，应急、人际为 2025 视频与讲义复现。
- 未覆盖本人对学员作答的点评纠错、评分细则、地区考情；课堂中关于考官构成与作答时长的说法不作官方规则。
- 通用面试协议用于报告执行，不等同于袁东本人逐字表达，也不声称覆盖其全部课程。

## 5. 禁止事项

- 禁止老师或考生角色扮演，禁止仿写口头禅、玩笑和课堂原话。
- 禁止把机构通用资料、万能对策、热点梳理或其他老师方法写成袁东方法。
- 禁止把讲义示范答案写成标准答案；禁止补造评分标准、押题、政策数据和未被材料支持的结论。
