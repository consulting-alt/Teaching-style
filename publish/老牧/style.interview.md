# 老牧 · 面试教学输出风格

## 1. 老牧材料支持的教学取向

- **题面先行**：先拆事实、对象、任务、矛盾和限制，再选分析工具；题型名称不能替代题目要求。
- **3F 审题**：用 Fact 看题面事实与边界，用 Feeling 识别题目中的情绪/价值倾向，用 Focus 锁定真正要回答的核心问题。
- **维度服务题面**：可按需要调用环境、行为画面、价值观、身份、愿景等维度，避免把维度清单变成固定段落。
- **主体分析**：说明不同主体的处境、作用、责任或影响，让观点和对策有对象依托。
- **具体落地**：组织、沟通和情境题交代对象、动作、顺序、权限、风险和反馈，避免只有态度和愿望。
- **题型意识**：区分观点/组织/情境模拟等任务；情境模拟要明确身份并直接沟通，不能只作第三人称汇报。
- **无领导取向**：关注能力考察、讨论逻辑、任务推进和真实稳定的人设，不机械扮演单一角色。

## 2. 基于材料的保守归纳

- 观点、社会现象或漫画题：先还原事实和核心矛盾，再判断；用少量相关主体、环境、行为或价值维度解释，必要时提出符合权限的方向。
- 组织及具体事务题：理解为完成工作或解决问题，围绕目标、对象、资源、流程、协同、风险和结果安排动作，不套万能组织模板。
- 情境模拟/沟通题：先确认身份、诉求、事实和边界，再组织理解、解释、行动与反馈；称谓、语气和权限随对象变化。
- 个人材料：只将可核验经历用于自我认知、演讲或观点支撑，讲清困难、行动、结果和反思，并回扣岗位能力。
- “环境/行为画面/价值观/身份/愿景”等是可选分析工具；材料只支持其作为方向，不能推出完整固定口诀或所有题型的统一流程。

## 3. 通用报告协议

### 报告定位与标准输出顺序

- 报告服务于复盘和下一次作答，不写成泛泛讲义、人物介绍或现场表演。
- 每题按以下顺序输出：**题目定位 → 有效内容 → 主要问题 → 修改动作 → 改写方向 → 验收标准**。
- 题目定位写清题型、任务、对象和核心要求；有效内容只保留原答案中贴题、具体、可复用的部分。
- 主要问题只抓最影响效果的 1—3 项；修改动作必须对应问题；改写方向不凭空增加经历、政策、数据、身份或权限。

### 题型检查重点

- **综合分析**：是否回应核心现象/观点；是否先给清楚、审慎的判断，再用主体、环境、行为或价值解释原因影响；对策是否对应问题，避免只喊态度或强行拔高。
- **组织题**：是否明确目标、对象、资源和评价标准；是否写清准备、实施、协同、风险、收尾/反馈；每一步是否有实际动作、责任对象和权限依据，避免把活动名称当方案。
- **情景模拟/沟通**：是否进入题目规定身份；是否称呼并回应对方诉求；是否完成解释、协商、行动和后续反馈，避免第三人称工作汇报或空泛表态。
- **应急题**：是否先控制最紧迫风险、保护人员和秩序，再核实事实、分工处置、沟通反馈和复盘；不擅自补造现场权限与资源。
- **无领导**：检查题型任务、讨论标准、观点依据、回应他人、推进共识和最终结果；关注真实稳定的协作表现。无领导报告不能套结构化题的 3F、组织或固定点评模板，必须按多人讨论和任务推进分析。

### 点评、改写与训练反馈

- 点评链条固定为：**题目要求 → 原答案实际表现 → 问题 → 修改动作 → 检查标准**；只描述听到/看到的内容，推测要标注不确定。
- 训练反馈统一写成“**问题 → 训练动作 → 验收标准**”。动作要小而明确，如限时先说结论、按对象列动作、删去重复句；验收看是否命中任务、补齐关键对象、顺序落地、内容收束。
- 答案改写优先修正题目偏移、对象遗漏和任务顺序，再处理措辞与节奏；保留有效信息，新增只限满足题目所需的通用动作。

### 无效长话、材料不足与安全判断

- **无效长话**：偏离题目、同义重复、用宏观口号代替动作，或只有态度愿望而缺少对象、顺序、边界、风险和结果；为凑时长堆砌金句、案例、排比也属无效。
- **材料不足**：先指出缺失的题干、录音、上下文或身份信息；用“可能、需核实”等保守表述，缩小结论，不用目录、ASR 猜测或模型补全填空。
- **验收标准**应可在下一次录音/文字答案中直接判断：是否答到任务、事实是否准确、动作是否具体、顺序是否合理、权限是否合适、每句话是否服务问题。

## 4. 证据与安全边界

- 本风格依据老牧配套 PDF，以及老牧课程目录、文件名和音视频元数据整理；视频尚未批量转写，抽样 ASR 仍待人工回听。
- 可保守使用 3F、上述维度工具、主体分析、题型意识、无领导能力考察/讨论逻辑/真实人设等方向；不把未核验片段写成逐字原话或完整方法。
- “二十字箴言”仅能确认课程存在相关模块，禁止补写原文；未人工核验的视频口播、完整固定口诀和完整解题流程均不作确定结论。
- 金句/排比 PDF 是配套汇编素材，不证明全部由老牧原创；热点资料只证明曾作为训练范围，使用时另行核对时效、出处和政策状态。

## 5. 禁止事项

- 禁止让老师或考生角色扮演，禁止仿写口头禅、粗俗表达或未经核验的口语风格。
- 禁止把机构通用方法、其他老师方法或报告编写者的推断写成老牧个人独有理论。
- 禁止把“二十字箴言”、未核验视频口播、完整固定口诀、虚构经历、数据、政策、权限或评分标准写成确定事实。
- 禁止把无领导当作结构化题作答，也禁止用角色标签替代真实讨论贡献。
