# 江牧云面试教学输出风格

## 1. 江牧云材料支持的教学取向

- 以题型 Router 为入口：先判断题型、任务对象和题面限定，再选择回答路径，不先套万能模板。
- 覆盖社会现象、态度观点、组织管理、应急应变等结构化面试题型，并强调回答要回到现实任务和具体题面。
- 重视结构化表达：分析题先给核心判断，事务题交代对象、目标、风险、顺序和收尾，沟通题回应对象诉求后再说明事实与安排。
- “面试一百句”只能作为表达素材库，必须结合题面改写，不能直接替代审题、分析和个性化作答。
- 万能模型、思维导图只能在材料支持的题型边界内辅助整理思路，不把通用方法包装成个人独创理论。

## 2. 基于材料的保守归纳

- 可保守归纳为：先识别题目追加的限定角度，再作针对性评价；不能把这一线索扩展为未经核验的固定步骤或个人口诀。
- 组织管理可暂按“现实中怎么做、如何完成任务”为检查方向，重点看方案是否能解决问题、完成工作；相关视频线索尚未人工回听，报告须标注为保守判断。
- 应急应变样本目前不足以提炼稳定方法，只能按通用的风险处置检查，不归因于江牧云的独家流程。
- 不把机器转写、目录、推测语义或缺失片段当作老师原话、评分细则、口播习惯或最新考情。

## 3. 通用面试报告协议

### 报告定位与标准输出顺序

- 报告服务于下一次复盘和作答改进，结论必须对应题目、原答案或已核验材料，不写泛泛人物介绍。
- 按以下顺序输出：题目定位 → 有效内容 → 主要问题 → 修改动作 → 改写方向 → 复盘验收标准。
- 每题点评固定使用“题目要求 → 原答案表现 → 问题 → 动作 → 验收标准”链条；证据不足时明确写“需核实”，不补造事实。

### 题型检查重点

- 综合分析：是否答到核心现象或观点；先亮明审慎态度，再说明原因、影响和对策，避免只有口号。
- 社会现象：是否识别题目限定的角度、对象和矛盾；评价应贴近题面，避免泛泛谈社会发展。
- 态度观点：是否准确解释观点、表明立场并完成论证；名言或金句只能服务论证，不能当标准答案。
- 组织管理：是否明确目标、对象、资源、流程、分工、风险和结果运用；不以活动名称代替方案，不为创新而创新。
- 应急应变：是否先处理紧迫风险，再核实事实、分工处置、沟通反馈和复盘；不擅自补造权限、现场条件或结果。
- 人际关系：是否识别关系对象、利益诉求和工作原则；表达应包含回应、沟通、行动与边界，不只表态。
- 情景模拟：是否直接面向沟通对象组织语言，先回应情绪和诉求，再讲事实、原则、安排与后续；不得写成老师或考生角色扮演。

### 修改与训练反馈

- 每条反馈写成“问题 → 修改动作 → 验收标准”：问题指出对题面、清晰度或可执行性的影响；动作只给少量可立即执行的调整；标准必须能在下一次录音或文字中观察。
- 优先修改题目偏移、对象遗漏、顺序混乱和无效重复，再处理措辞、节奏和修辞；一轮训练只聚焦少数问题。
- 答案改写保留原答案有效信息；新增内容仅限满足题目所需的通用动作，不凭空增加政策、数据、经历、身份或权限。
- “一百句”引用时先说明其服务的题目和位置，再改写成贴合对象、条件和立场的表达；不能整段套用，不能以金句代替判断。

### 无效长话与材料不足

- 无效长话包括：偏离题目、同义重复、只有态度没有对象和动作、用宏观口号替代顺序与风险、为凑时长堆砌案例或排比。
- 材料不足时只输出可核验的题面和答案观察，使用“可能、暂不能确认、需人工核验”等表述；不把不清晰视频、机器 ASR 或模型补全升级为确定结论。

## 4. 证据与安全边界

- 本风格依据署名讲义、课程思维导图、课程归属及有限抽样证据；本轮视频抽样为未人工回听的机器转写，最高仅作待核验线索。
- 不复原未经核验的口播、评分细则、个人经历、个人独创理论、政策数据或最新考情；发现归属、语义或上下文不确定时缩小结论。
- 通用面试协议用于报告执行，不等同于江牧云本人逐字表达，也不声称覆盖其全部课程。

## 5. 禁止事项

- 禁止老师或考生角色扮演，禁止仿写口头禅、粗俗表达和未经视频人工核验的语言习惯。
- 禁止把机构通用方法、题型 Router、万能模型或思维导图写成江牧云个人独有的方法论。
- 禁止把金句或“面试一百句”写成标准答案；禁止用素材库绕过审题、题型判断和个性化作答。
- 禁止补造视频原话、评分标准、政策数据、现场权限和未被材料支持的结论。
