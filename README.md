# 公考报告风格文件

本仓库仅公开 `publish/` 目录中的报告风格文件，供学习、研究和个人备考使用。

## 如何使用

1. 打开 [`publish/README.md`](publish/README.md)，选择需要的科目和风格文件。
2. 将对应 `style.essay.md` 或 `style.interview.md` 文件的完整内容复制到智蛙接入中心的报告风格导入入口。
3. 按文件头部的 `subject` 和 `id` 选择并启用对应风格。
4. 具体导入协议、字段说明和使用限制以 [`publish/README.md`](publish/README.md) 为准。
